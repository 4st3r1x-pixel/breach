CVE-2026-59310

vCenter wide open: a path-traversal flaw hits 47 countries

A directory-traversal vulnerability in VMware vCenter Server, the console IT teams use to run entire fleets of virtual machines, was exploited in the wild just five days after Broadcom published its fix. Researchers tracked several hundred compromised IP addresses across 47 countries, with Babuk ransomware deployed on the affected systems.

The flaw was reported by researcher Salvatore Gulizia, who was rewarded for the finding. Cisco Nexus 9000 (and 3000) series
Status
Patch available

The flaw sits in the switches' Silicon One integration. TCP ports 43210 and 43211, reachable by default in the default layer-3 VRF, expose the vulnerable service to the network. Inventorying exposed switches and filtering these ports is recommended alongside patching.

SonicWall confirmed active exploitation suggesting attackers are chaining both flaws together. A successful compromise can provide a foothold close to authentication infrastructure, with risks of credential theft and lateral movement toward internal applications.

The first vulnerability affects the web admin interface and lets an unauthenticated remote attacker modify system configuration. The second allows unsafe dynamic loading of Java classes in the database connection utilities. Combined, they offer a plausible path to arbitrary code execution.
